# 牌桌报牌与炸弹动效设计

## 目标

- 移除主界面的“牌局信息”侧栏。
- 新开牌局默认从级牌 2 开始。
- 玩家剩余 1 至 9 张牌时，在对应座位显示动态报牌旗。
- 实时牌局中打出炸弹、王炸或同花顺时，在对应座位附近播放 2 秒爆炸动画。

## 界面结构

主界面保留牌桌和 AI 组牌建议区域，完整删除“牌局信息”栏、折叠按钮、折叠状态及相关快捷键逻辑。删除侧栏后，牌桌区域使用现有网格的剩余空间，不新增替代面板。

默认级牌常量从 `10` 改为 `2`。首次打开和点击“开房”时，界面选择值与创建房间请求均使用级牌 2；后续结算晋级仍沿用现有规则。

## 报牌旗

报牌旗属于座位面板的视觉状态，由 `player.handCount` 直接派生：

- `1 <= handCount <= 9`：显示“还剩下 X 张了”。
- `handCount >= 10`：不显示。
- `handCount === 0`：旗帜下降并消失，已有游次徽章继续显示。

旗帜从对应座位朝牌桌中心升起，四个座位使用相同组件和按座位调整的方向样式。牌数变化只更新文字，不重复播放入场动画。动画不得遮挡手牌数量、游次徽章、当前出牌或操作按钮。

## 爆炸动画

爆炸动画只响应实时 API 操作成功后新增的出牌记录。触发牌型：

- `bomb`
- `joker-bomb`
- `straight-flush`

动画显示在出牌座位靠近牌桌中心的位置，持续 2 秒后自动卸载。同一时刻的新炸弹事件替换上一事件并重新计时。

以下情况不触发：普通牌型、过牌、首次加载已有房间状态、页面刷新恢复状态、打开或操作本局回顾。

实现使用 React 状态和 CSS 动画，不引入新依赖。系统启用 `prefers-reduced-motion: reduce` 时取消位移和缩放，仅保留短暂静态提示并按同样时限消失。

## 状态与数据流

每次实时操作成功后，将更新前后的 `playHistory` 比较。只检查新增加的记录，取最后一条新增的 `play`；若其牌型符合触发条件，则设置 `{ seat, eventId }` 动画状态并启动 2 秒定时器。组件卸载或新事件到来时清理旧定时器。

回放组件继续只读取 `playHistory` 用于展示，不接入爆炸动画状态。

## 测试

UI 单元测试覆盖：

- 初始级牌为 2，创建房间请求使用 2。
- 页面不再渲染“牌局信息”栏。
- 1 至 9 张显示报牌旗，10 张和 0 张不显示。
- 实时更新后旗帜数字同步变化，出完后消失。
- 炸弹、王炸、同花顺实时出牌触发动画，并在 2 秒后消失。
- 普通出牌、过牌、初次加载及回放不触发动画。

## 非目标

- 不修改后端房间协议。
- 不在回放中增加报牌或爆炸事件动画。
- 不修改结算、进贡还贡和晋级规则。
